# Bus Management System

A Java-based Bus Management System developed using Object-Oriented Programming (OOP) concepts.

## Concepts Used
- Classes and Objects
- Encapsulation
- Constructors
- Inheritance
- Multilevel Inheritance
- Method Overriding
- Polymorphism
- Abstraction
- Packages
- Access Modifiers
- ArrayList
- Scanner
- Exception Handling
- Static Methods
- Final Methods

## Bus Types
- Regular Bus
- Luxury Bus
- VIP Luxury Bus
- Mini Bus

## Tools Used
- Java
- IntelliJ IDEA
- GitHub
